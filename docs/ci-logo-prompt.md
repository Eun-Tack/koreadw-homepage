작성일 2026-10-13 · 대상 47개 · 전체 비교표: [ci-logos-original.png](ci-logos-original.png)

---

## 0. 가장 중요 — 로고를 "생성"하면 안 됩니다

이건 **이미지 생성 작업이 아니라 이미지 처리 작업**입니다.

| 해야 할 것 | 하면 안 되는 것 |
|---|---|
| 기존 파일을 잘라내고 크기 맞추기 | 로고를 새로 그리거나 다시 만들기 |
| 여백 제거, 배경 흰색으로 통일 | 글자·도형·색을 바꾸거나 "개선"하기 |
| 한 폴더에 규격 통일해 저장 | 비슷하게 생긴 이미지로 대체하기 |

전부 **타사 상표**입니다. 한 획이라도 달라지면 상표를 훼손한 것이 되고,
고객사가 거래처에 보여주는 화면이라 바로 문제가 됩니다.

**반드시 코드(Python + Pillow)로 원본 파일을 변환**하게 하세요.
GPT를 쓰신다면 **이미지 생성이 아니라 코드 인터프리터(데이터 분석)** 기능이어야 합니다.

## 2. 그대로 붙여 쓰실 프롬프트

```
업로드한 47개의 기업·기관 로고 이미지를 웹사이트에 나란히 배치하기 위해
규격을 통일해 주세요.

[매우 중요]
- 이미지를 새로 생성하지 마세요. 반드시 Python(Pillow)으로 원본 파일을
  변환하는 방식으로만 처리하세요.
- 로고의 모양, 글자, 색상은 절대 바꾸지 마세요. 실제 기업의 상표입니다.
- 작업은 잘라내기, 여백 제거, 크기 조정, 배경 통일만 허용됩니다.

[처리 순서]
1. 투명 배경(RGBA/LA/팔레트 투명) 이미지는 흰색 배경 위에 합성하세요.
   알파를 그냥 버리면 투명한 부분이 검게 변합니다. 반드시
   Image.alpha_composite 를 쓰세요.

2. 로고 주변의 빈 여백을 잘라내세요.
   흰색(RGB 각 채널 246 이상)으로만 이루어진 가장자리 행과 열을 제거합니다.
   ImageChops.difference 로 경계상자를 구해도 됩니다.

3. 잘라낸 로고를 가로 400px · 세로 160px 캔버스 한가운데에 배치하세요.
   - 비율은 반드시 유지합니다 (늘이거나 찌그러뜨리지 마세요).
   - 로고가 들어갈 최대 영역은 320x104px 입니다. 이 안에 들어가도록
     축소하고, 원본이 작으면 확대하지 말고 원래 크기로 두세요.
   - 남는 공간은 흰색으로 채웁니다.
   - 리샘플링은 LANCZOS 를 쓰세요.

4. PNG로 저장하세요. 파일명은 logo-001.png 부터 logo-047.png 까지
   원본 파일명 순서대로 붙이고, 모두 같은 폴더(logos/)에 넣으세요.

5. 아래 파일 하나는 로고 자체에 짙은 남색 배경이 칠해져 있습니다.
   이것만 예외로, 배경을 흰색으로 바꾸지 말고 원본 그대로 두되
   3번의 캔버스 규격만 맞춰 주세요. (흰 글자라 배경을 지우면 사라집니다)
     → 718x82 크기의 BMP 파일 (한국도로교통공단 / 도로교통연구원)

[마지막에 확인해 주세요]
- 47개 전부 400x160 인지
- 로고가 찌그러지지 않았는지
- 가장자리에 회색 띠나 잘린 글자가 없는지
- 결과를 8열짜리 비교표 이미지 한 장으로 만들어 보여주세요

작업에 사용한 Python 코드도 함께 알려주세요.
```

## 3. 왜 이 수치인가

| 항목 | 값 | 이유 |
|---|---|---|
| 캔버스 | 400 × 160 | 5:2. 가로로 긴 로고(최대 8.8:1)와 정사각 로고(1:1)를 한 틀에 담는 비율 |
| 안쪽 여백 | 40 / 28 | 로고끼리 붙어 보이지 않게. 그리드에서 숨 쉴 공간 |
| 출력 배수 | 2배 | 화면에 200×80으로 깔 계획이라 고해상도 화면 대비 2배 |

원본이 **130×38부터 2362×822까지 18배 차이**가 납니다.
이대로 깔면 로고마다 크기가 제각각으로 보여서, 캔버스 통일이 필요합니다.

## 4. 현재 상태 (제가 분석한 결과)

47개를 흰 배경에 합성해 확인한 결과입니다.

- **46개는 흰 배경에서 그대로 멀쩡합니다.** 여백 제거와 크기 통일만 하면 됩니다
- **1개만 배경 처리가 필요합니다** — 718×82 BMP (한국도로교통공단·도로교통연구원).
  짙은 남색 바탕에 흰 글자라 배경을 지우면 글자가 사라집니다
- 투명 PNG가 19개 있는데, 흰 배경 합성만 제대로 하면 문제없습니다
