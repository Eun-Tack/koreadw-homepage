## 1. 사이트의 목적 (D1-1, D1-2)

고객이 적은 방문자와 우선순위입니다. 개별 지시는 아니지만 모든 판단의 기준입니다.

> 1. 기존 고객의 소개를 받고 업체를 확인하려는 고객
> 2. 리서치 과제를 진행하려 업체를 탐색 중인 고객

> **1순위**: KDW에 용역을 맡겨도 문제가 없을거라는 신뢰를 준다
> **2순위**: 예산과 일정의 감을 잡을 수 있게 해준다
> **3순위**: 빠르게 우리와 접촉할 수 있는 채널을 알려준다

1순위를 푸는 방법으로 고객이 적은 것

> 일을 많이해 본 회사다 : 주요 클라이언트 나열 / 눈에 띄는 성과
> 일을 오래해본 회사다 : 연혁
> 국가/공공기관의 인정 받은 회사다 : 각종 인증서 / 수상 경력
> 성향이 맞는 / 친밀감이 느껴지는 회사다 : 광복회 활동 등

| 항목 | 상태 |
|---|---|
| 주요 클라이언트 나열 | 완료 — 47곳 |
| 연혁 | 완료 — 타임라인 25건 |
| 인증서 / 수상 경력 | 완료 — 분류 필터 `인증 · 선정` |
| 광복회 활동 등 | 완료 — 분류 필터 `대외 활동` |
| 접촉 채널 — 메일 · 전번 · 지도 | 완료 |
| 접촉 채널 — **SNS** | **미반영** |

> 샘플, 분석 방법 등에 따른 기간 명시 **최저 금액**
> 결국 통화/메일로 판단해야할테니 대략적인 수준

금액 공개 여부는 회사가 정할 사항이라 보류 중입니다.

## 11. 고객 요청과 다르게 처리한 것 — 설명이 필요합니다

| 요청 | 처리 | 이유 |
|---|---|---|
| 첫 화면 `이미지 롤링` | 대형 타이포 + 추상 비주얼 | 리서치 회사 6곳 중 증빙 문서를 첫 화면에 돌리는 곳이 없었음. 자료는 연혁 타임라인에 모음 |
| 연혁 / 성장 스토리 분리 | 하나의 타임라인으로 통합 | 같은 사실이 두세 곳에 중복(대구일보 6회, 광복 80주년 5회) |
| 경력 라벨 | 네 장 모두 `리서치경력` | 주석이 카드마다 엇갈림 |
| 자격증 · 확인서 원본 | 자격번호 · 생년월일 · QR 마스킹 | 개인정보 · 도용 위험 |
| 연구진 사진 파일 | 서버에서 삭제 | 화면에서만 빼면 주소로 접근 가능 |
