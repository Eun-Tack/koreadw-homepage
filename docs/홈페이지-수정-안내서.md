# 홈페이지 수정 안내서

(주)코리아데이터월드 홈페이지를 직접 고치실 때 보는 문서입니다.

지금 쓰고 계신 관리자(`koreadw.co.kr/admin`)에서 전부 하실 수 있습니다.
새로 설치하거나 가입할 것은 없습니다.

---

## 먼저 알아두실 것 세 가지

**1. 두 가지 방식이 있습니다**

| | 어떻게 | 무엇을 |
|---|---|---|
| **글쓰기** | 지금 공지 올리시듯 | 공지사항 |
| **화면 고치기** | 정해진 줄을 복사해서 고침 | 연혁, 연구진, 전화번호 등 |

공지사항은 지금 하시던 그대로입니다. 나머지는 이 문서의 규칙대로 하시면 됩니다.

**2. 고치기 전에 반드시 복사해 두세요**

수정 화면에 들어가면 **「소스복사」** 단추가 있습니다. 누르면 지금 내용이
복사됩니다. 메모장에 붙여넣어 두시면, 잘못되었을 때 그대로 되돌릴 수 있습니다.

**3. 중괄호 `{ }` 는 넣지 마세요**

`{` 와 `}` 는 홈페이지 프로그램이 명령으로 읽습니다. 글 안에 들어가면
**페이지 전체가 하얗게 되거나 영어 오류 글자가 뜹니다.**
그런 경우 복사해 둔 내용을 다시 붙여넣고 저장하시면 돌아옵니다.

## 1. 공지사항 올리기

지금 하시던 그대로입니다. 바뀐 것은 **올리시면 첫 화면에도 자동으로 올라간다**는
점입니다. 따로 알려주지 않으셔도 됩니다.

**제목 앞에 분류를 붙여 주세요.**

```
[소식] (주)코리아데이터월드, 한국보훈진흥회와 업무협약 체결
[공지] 2026년 설 연휴 안내
[언론] KBS 뉴스에 조사 결과 보도
[안내] 사무실 이전 안내
[조사 안내] 2026년 고객만족도 조사 실시
```

대괄호 안의 분류가 홈페이지에서 작은 색 딱지로 바뀌어 보입니다.
붙이지 않으셔도 글은 정상으로 올라갑니다.

사진은 글 안에 넣으시던 대로 넣으시면 됩니다.

## 2. 연혁에 한 줄 더하기

**가는 길** · 디자인 관리 → 상세페이지 디자인 → 새 페이지 → `kdw_history` 줄의 **설정**
→ 오른쪽 위 **「소스편집」**

이런 모양이 보입니다.

```html
<h4>2026</h4>
<p>10.12 [협약] 한국보훈진흥회 업무협약 체결 | 보훈 정책 연구와 여론조사 협력</p>
<p>10.09 [활동] 양평군 2026 제2차 정책 포럼 참석 | 대표 및 임직원</p>

<h4>2025</h4>
<p>12.31 [언론] '대구일보' 여성기업 특별기획 1면 전면 인터뷰</p>
```

**한 줄이 연혁 한 칸입니다.** 줄 하나를 통째로 복사해서 내용만 바꾸세요.

```
<p>날짜 [분류] 내용 | 설명</p>
```

| 자리 | 쓰는 법 | 빠뜨려도 되나 |
|---|---|---|
| 날짜 | `10.12` (10월 12일) · 날짜를 모르면 `10` 만 | 아니오 |
| 분류 | `[인증] [협약] [언론] [활동] [사내]` 중 하나 | 예 (없으면 사내) |
| 내용 | 연혁에 남길 한 줄 | 아니오 |
| 설명 | `|` 뒤에 덧붙이는 짧은 설명 | 예 |

**새 해를 시작하실 때**는 맨 위에 이렇게 더하세요.

```html
<h4>2027</h4>
<p>01.15 [협약] ○○기관 업무협약 체결</p>
```

> 분류는 적어 주신 것에 따라 색 딱지와 위쪽 분류 단추가 **저절로 만들어집니다.**
> 단추를 따로 고치실 필요가 없습니다.

## 3. 전화번호 · 주소 · 이메일 바꾸기

맨 아래 회사 정보는 **모든 페이지가 같은 곳을 보고 있습니다.** 한 번만 고치면 됩니다.

**가는 길** · 디자인 관리 → 레이아웃 → `KDW`

아래쪽에서 이 부분을 찾으세요.

```html
<p class="ftr-addr"><b>서울 본사</b> 서울특별시 영등포구 국회대로72길 11, 309/310호<br>
<b>대구 지점</b> 대구광역시 달서구 달서대로 54, 503호</p>
```

```html
<b>(주)코리아데이터월드</b> &nbsp;|&nbsp; 대표이사 김근지 &nbsp;|&nbsp; 사업자등록번호 296-81-00459<br>
전화 02-780-2273 &nbsp;|&nbsp; 팩스 070-8800-2273 &nbsp;|&nbsp; 메일 <a href="mailto:contact@koreadw.co.kr">contact@koreadw.co.kr</a>
```

**글자만 바꾸세요.** `<b>` `&nbsp;` `<br>` 같은 것은 그대로 두셔야 모양이 유지됩니다.

이메일을 바꾸실 때는 **두 군데**를 같이 바꾸세요.
`mailto:새주소` 와 그 뒤에 보이는 글자, 둘 다입니다.

## 4. 연구진 추가 · 수정 · 삭제

**가는 길** · 새 페이지 → `kdw_people` → 설정 → 소스편집

한 사람이 이렇게 한 덩어리입니다.

```html
<article class="person reveal">
<h3>박혜진<small>책임연구원 · 연구 1팀장</small></h3>
<dl class="person-meta">
<div><dt>리서치경력</dt><dd>8년 · 프로젝트 400회 이상</dd></div>
<div><dt>이력</dt><dd>現 코리아데이터월드</dd></div>
<div><dt>학력</dt><dd>연세대학교 사학과 학사</dd></div>
</dl>
</article>
```

- **고칠 때** — `<dd>` 와 `</dd>` 사이 글자만 바꾸세요
- **줄을 늘릴 때** — 한 칸 안에서 줄을 나누려면 `<br>` 를 넣으세요
  예: `<dd>現 코리아데이터월드<br>前 ○○리서치</dd>`
- **항목을 더할 때** — `<div><dt>자격</dt><dd>사회조사분석사 2급</dd></div>` 처럼 한 줄 추가
- **사람을 더할 때** — `<article>` 부터 `</article>` 까지 통째로 복사해서 내용 교체
- **사람을 뺄 때** — `<article>` 부터 `</article>` 까지 통째로 지우기

> 자격증 사진이 붙은 분은 `person-certs` 로 시작하는 줄이 더 있습니다.
> 그 줄은 **건드리지 말고 그대로 두세요.** 자격증을 바꾸셔야 하면 연락 주세요.

## 5. 주요 클라이언트(고객사) 추가

로고 그림이 필요하므로 두 단계입니다.

**① 로고 올리기** · 디자인 관리 → FTP(이미지관리) → `images` → `kdw` → `clients`
→ 로고 그림을 올립니다. 파일 이름은 `logo-48.png` 처럼 **겹치지 않는 번호**로 하세요.

**② 목록에 한 줄 더하기** · 디자인 관리 → 메인페이지 → 소스편집

비슷한 줄을 찾아 바로 아래에 복사해 넣으세요.

```html
<li><img src="/images/kor01-14-0033/kdw/clients/logo-48.png" alt="○○기관" width="400" height="176" loading="lazy" decoding="async"><span>○○기관</span></li>
```

`logo-48.png` 와 **기관 이름 두 곳**(`alt=` 뒤, `<span>` 안)만 바꾸시면 됩니다.

> 제목 옆의 기관 수(`국책 · 지자체 연구기관 23`)는 **저절로 다시 세어집니다.**
> 숫자를 고치실 필요가 없습니다.

## 6. 그 밖의 글자 고치기

| 무엇을 | 어디서 |
|---|---|
| 대표이사 인사말 | 새 페이지 → `kdw_greeting` |
| 조직도 | 새 페이지 → `kdw_org` |

모두 **글자만 바꾸시면 됩니다.** `<` 로 시작하고 `>` 로 끝나는 부분은
모양을 만드는 표시이니 그대로 두세요.

## 손대지 마셔야 할 곳

아래는 잘못 건드리면 **홈페이지 전체 모양이 깨집니다.** 필요하시면 연락 주세요.

- 디자인 관리 → **CSS/JS** (스타일시트 · 자바스크립트)
- 디자인 관리 → 레이아웃의 **윗부분**
  (`<head>` 안쪽, `{_DESIGN...}` `{{BODY}}` 처럼 중괄호가 있는 줄)
- 디자인 관리 → 게시판 → 목록화면 · 읽기화면

## 잘못되었을 때

**1) 글자가 깨지거나 모양이 틀어졌다**
고치기 전에 복사해 둔 내용을 다시 붙여넣고 저장하세요.

**2) 복사해 둔 것이 없다**
수정 화면의 **「소스복구」** 단추를 누르면 직전 내용으로 돌아갑니다.

**3) 페이지가 하얗게 되거나 영어 오류가 떴다**
방금 넣은 글에 `{` 나 `}` 가 들어갔을 가능성이 큽니다. 그 글자를 지우고 저장하세요.

**4) 그래도 안 된다**
디자인 관리 → **디자인저장/복구** 에서 이전 상태로 되돌릴 수 있습니다.

## 정리

| 하시는 일 | 얼마나 자주 | 어디서 |
|---|---|---|
| 공지사항 올리기 | 한 달에 한두 번 | 게시판 (지금 그대로) |
| 연혁 한 줄 추가 | 분기에 한 번쯤 | `kdw_history` |
| 연구진 바뀔 때 | 드물게 | `kdw_people` |
| 전화·주소 바뀔 때 | 드물게 | 레이아웃 `KDW` |
| 고객사 추가 | 드물게 | FTP + 메인페이지 |

공지사항만 올리셔도 홈페이지는 계속 살아 있습니다.
나머지는 바뀔 일이 생길 때만 보시면 됩니다.
