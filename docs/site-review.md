# 공개 사이트 품질 검토 및 수정

검토일: 2026-10-12

대상: https://eun-tack.github.io/koreadw-homepage/ 의 공개 페이지 13개.
실제 배포본을 Chromium으로 탐방하고, 수정본을 1440·768·390·320px에서 검증했다.

## 반영 내용

- 모바일 하위 메뉴: 스크롤 영역의 너비를 제한하고 좌우 이동 버튼을 추가했다. 현재 메뉴를 화면 안으로 이동하며, 회사소개·사업소개 마지막 링크까지 스크롤하고 실제 이동하는 검사를 추가했다.
- 조직도: 분야별 자문위원과 경영지원팀을 독립 영역으로 배치하고 부서를 4열로 수정했다. 모바일에서는 2열로 표시한다.
- 연혁: 날짜와 설명을 두 열로 구분하고 괄호 설명을 본문 안에 포함했다. 연도와 세로축 사이 여백을 확보했다.
- 특수설문: 겹친 덱을 탭별 단일 예시 패널로 바꿨다. 출력 형식까지 잘리지 않으며, 아래 상세 영역에는 활용 분야와 결과물을 남겨 정의의 반복을 줄였다. 키보드 탐색과 JavaScript가 없는 환경도 지원한다.
- 조사방법: 카드 상단 여백을 줄이고 제목 옆에 일러스트를 배치했다. 피사체가 차지하는 비율에 따라 표시 배율을 보정했다.
- 공지사항: breadcrumb의 중복을 없애고 푸터 그룹명을 고객지원으로 변경했다. 태그가 없는 항목은 소식 배지로 정렬했다. 상세 페이지가 없는 목록의 자기 자신 링크를 제거했다.
- 인사말: 인용구의 강제 줄바꿈과 중복된 대표이사 사진 캡션을 제거했다.
- 연구원: 설명 왼쪽·증명사진 형태의 사진 오른쪽인 카드로 변경했다. 기존 실제 사진을 유지하면서 3:4 프레임, 크롭과 배율을 통일하고 가장자리 결함선을 가렸다.
- 오시는 길: 기존 서울·대구 주소를 기준으로 Google 지도 두 개를 삽입했다. 네이버 지도 검색과 Google 길찾기 링크를 함께 제공한다. 실제 지도 타일과 위치 핀을 별도로 확인했다.
- 진행 절차: 단계 카드의 읽기 흐름을 정리하고 조사 목적·희망 일정·견적 상담 안내를 추가했다.
- 공통: 누락된 부제, 본문 대비, 모바일 글자 크기와 간격을 정리했다. CSS·JS 내용 기반 버전을 적용해 배포 후 오래된 캐시와 섞이는 것을 방지한다.

## 검증

- 13페이지 × 4개 너비 = 52개 화면 검사 통과: 문서 가로 넘침, 깨진 이미지, 페이지 JavaScript 오류 없음.
- 메인·특수설문 페이지의 5개 탭 클릭과 방향키·Home·End 조작, 패널 잘림 검사 통과.
- 회사소개·사업소개 하위 메뉴 끝까지 이동 후 마지막 링크 클릭 검사 통과.
- 모바일 메뉴 열기·닫기·Escape·상담 링크, 사진 비율, 조직도 겹침 검사 통과.
- 로컬 링크·파일 존재 여부, 단일 파일 미리보기의 탭과 ID 중복, JavaScript 미사용 시 예시 노출 검사 통과.

재현 방법(Python 및 Playwright Chromium 필요):

```sh
python build.py
python tools/review_site.py --widths 1440,768,390,320 --output .review/final
python tools/check_site.py --output .review/final-interactions
```

공개 사이트 재검사는 두 검사에 `--base https://eun-tack.github.io/koreadw-homepage/`를 추가한다.
스크린샷과 JSON 결과는 버전 관리에서 제외한 `.review/`에 저장한다.
