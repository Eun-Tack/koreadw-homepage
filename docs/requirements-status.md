자주 바뀌는 내용은 **빌드 스크립트를 열지 않고** 텍스트 파일만 고치면 됩니다.

| 파일 | 내용 | 읽는 코드 |
|---|---|---|
| `content/notices.md` | 공지사항 | `build.py:77` |

| `content/clients.md` | 주요 클라이언트 분류·수록 | `build.py:111` |

고친 뒤 `python build.py` 실행 → 커밋 → 푸시하면 반영됩니다.

**배포 대상별 빌드** (`build.py:27` BASES, `build.py:1465` make_bundle)

```
python build.py                 시연용 (기본) · github.io
python build.py --prod --bundle 납품용 · dist/ 에 올릴 파일만 추출
python build.py --base=URL      Vercel 등 임시 주소
```
