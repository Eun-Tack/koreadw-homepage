## 2. 템플릿 문법

빌더는 화면마다 HTML 템플릿을 직접 고칠 수 있습니다. 문법은 이렇습니다.

```
{@LIST} ... {:} ...없을 때... {/}     목록 반복 (없으면 {:} 뒤가 나옴)
{.bbs_title}  {.url_view}            반복 안의 값
{.bbs_reg_date}  {.cate_name}
{?조건} ... {/}                      조건
{totalNum}  {pagebar}  {page}        전체 건수 · 페이지 번호
{{게시판새글/notice/템플릿/3/1/60/0}}  다른 화면에 새 글 끌어오기
{{BBS_EXTRACT/notice/5/1/40/0}}      위와 같음 (영문 표기)
{dataSetup.bbss_header_html}         게시판 위에 넣는 내 HTML
{dataSetup.bbss_footer_html}         게시판 아래에 넣는 내 HTML
```

`{` `}` 가 문법이라 **본문에 CSS·JS 를 넣으면 페이지가 죽습니다**. 실제로 겪었습니다.
CSS·JS 는 `디자인 관리 > CSS/JS` 로만 넣습니다.

## 5. 이미 있는 다른 것들

- **게시판 3개** — 공지사항(`notice`, 47건) · 문의게시판(`freeboard`) · FAQ(`faq`)
- **추가 페이지 9개** — `company_greeting` `company_history` `company_map` `sub1_4`(조직도)
  `business`(조사분야) `sub3_1`(**견적문의**) `cb`(복리후생) `kdw_test`(우리가 만든 시험용)
  견적문의 페이지가 이미 있다는 건, 고객이 그 창구를 쓰고 있었다는 뜻입니다.
- **신청폼 · 설문 · 예약 · 일정 모듈** — 쓰지 않고 있지만 기능은 있습니다. 견적문의 폼에 쓸 수 있습니다.
- **이미지 서버** — `/images/kor01-14-0033/` 아래에 기존 디자인 이미지, `/data/file/` 에 게시물 첨부

## 6. 제약

- 본문에 중괄호 금지 (위 2번)
- 주소가 `?act=info.page&pcode=…` 형태가 됩니다
- 브라우저 탭 제목이 전 페이지 공통입니다 (`{_SITE.site_browser_title}`)
- `https://koreadw.co.kr` 인증서가 self-signed 이라 **지금은 HTTP 전용**입니다
- 모바일 홈페이지 사용이 꺼져 있어 모바일도 PC 레이아웃을 받습니다 →
  우리 반응형 CSS 가 그대로 동작하므로 **이 설정은 그대로 두어야 합니다**
- `common.css` · `common.js` 는 지금 사이트가 쓰는 공용 파일이라,
  바꾸는 순간 현재 디자인이 바뀝니다. 이식 맨 마지막에 해야 합니다
