7손대지 마셔야 할 곳

아래는 잘못 건드리면 홈페이지 전체 모양이 깨집니다. 필요하시면 연락 주세요.

  • 디자인 관리 → CSS/JS (스타일시트 · 자바스크립트)
  • 디자인 관리 → 레이아웃의 윗부분 — <head> 안쪽, {_DESIGN…} {{BODY}} 처럼 중괄호가 있는 줄
  • 디자인 관리 → 게시판 → 목록화면 · 읽기화면

8잘못되었을 때

  1. 글자가 깨지거나 모양이 틀어졌다
    고치기 전에 복사해 둔 내용을 다시 붙여넣고 저장하세요.
  2. 복사해 둔 것이 없다
    레이아웃과 메인페이지에는 소스복구 단추가 있습니다. 누르면 직전 내용으로 돌아갑니다.
  3. 페이지가 하얗게 되거나 영어 오류가 떴다
    방금 넣은 글에 { 나 } 가 들어갔을 가능성이 큽니다. 그 글자를 지우고 저장하세요.
  4. 그래도 안 된다
    디자인 관리 → 디자인저장/복구 에서 이전 상태로 되돌릴 수 있습니다.
